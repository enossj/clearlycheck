How test scores become percentages and letter grades

A test score is really just a fraction turned into a percentage. If every question is worth the same amount, the calculation is (total questions − wrong answers) ÷ total questions × 100. If questions carry different point values, it's points earned ÷ points possible × 100. Either way, once you have a percentage, a letter grade is just that percentage sorted into a bucket — 93% and up is usually an A, 90–92% is an A-, and so on down to F below 60%. This calculator does both steps at once: enter your raw numbers in whichever mode matches how the test was graded, and it returns the percentage and letter grade instantly.

Questions mode vs. Points mode — which should I use?

Questions mode is the right choice for tests where every question counts equally — a 20-question multiple-choice quiz, for example, where each question is worth 5%. You only need two numbers: how many questions were on the test, and how many you got wrong. Points mode is for tests where questions are worth different amounts — a short-answer test where one question is worth 2 points and another is worth 10. There, you need the total points you earned and the total points the test was worth. Using the wrong mode won't necessarily break the math, but it can give a misleading percentage if question weights actually vary, so match the mode to how your teacher actually graded the test.

What is an EasyGrader chart, and why does it only appear in Questions mode?

Long before spreadsheets, teachers used printed "EasyGrader" charts or plastic grading wheels to skip the arithmetic entirely — the chart lists, for a given number of questions, the percentage and letter grade attached to every possible number of wrong answers. This calculator reproduces that chart automatically for Questions mode, covering everything from a perfect score down to missing every question (or the first 20 rows, whichever comes first, so the table stays a manageable size). Points mode doesn't have an equivalent chart, since the number of ways to lose points varies question by question rather than following a simple count.

Why letter grade cutoffs differ from school to school

There's no single authority that defines what percentage counts as a B or a C — grading scales are set locally, by a school district, an individual school, or sometimes an individual instructor. The 10-point scale with plus and minus grades shown below is the most common convention used across US schools and colleges, and it's what this calculator uses by default. But some instructors skip the plus/minus distinctions entirely, some shift a cutoff by a point or two, and some use entirely different scales. Treat the letter grade here as a well-informed estimate, and check your syllabus or gradebook for the cutoffs that actually apply to your class.
